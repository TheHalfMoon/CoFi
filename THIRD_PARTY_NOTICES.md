# Third-Party Notices

Community Finance / CoFi includes founder-authorized imported source snapshots from external donor projects.

The original notices, license files, copyright statements, package metadata, and third-party attributions contained within each pinned donor source tree are preserved inside that snapshot.

Canonical donor lineage and commit pins are recorded in `UPSTREAM.md` and `upstream/import-manifest.json` once P00 import completes.

This file is additive and does not replace donor-specific notices embedded in imported source trees.
